# AI向け NTA手引DB クイックスタート（1URL≒1万トークン制約向け）

# 基本方針:
# 1) 小さい索引で item_id を決める
# 2) resolve_liteのpartを開いて item_id を決める
# 3) 本文は text/{doc_code}/{item_id}.txt を読む
# 4) 引用URLが必要なときだけ enhanced/...#pX を使う

# 入口
# - https://jplawdb.github.io/html-preview/ai-nta-guide-db/llms.txt

# - https://jplawdb.github.io/html-preview/ai-nta-guide-db/data/shards_index.json

# 本文URL
# - https://jplawdb.github.io/html-preview/ai-nta-guide-db/text/{doc_code}/{item_id}.txt
