## 共通URLルール（全DB横断チートシート）

base = https://jplawdb.github.io/html-preview/

- 本文テキスト: `{base}{db}/text/{code}/{id}.txt`（法令/通達/QA/手引）、`{base}{db}/core/{id}.txt`（判決）、`{base}{db}/packs/*.txt`（文献/条約）、`{base}beppyo-db/beppyo/{ID}.txt`（別表）
- 根拠HTML: `{base}{db}/enhanced/{code}/{id}.html#pX`（項）/ `#pX-iY`（号）
- shard索引: `{base}{db}/data/shards_index.json` → `{base}{db}/data/shards/shard-XX.txt`（TSV。キーワード検索用）
- 目次索引: `{base}{db}/data/resolve_lite/index.json` → `{base}{db}/data/resolve_lite/{code}.json`（項番一覧）
- 英字キーワード検索: `{base}{db}/data/latin_terms/index.json` → `{base}{db}/data/latin_terms/*.tsv`（文献/条約DB）

## 読み込みコスト目安

- ID判明（条番号・通達番号・別表番号等）→ 直接アクセスで**1回**（索引スキップ推奨）
- キーワード検索 → shards_index + shard-XX.txt + 本文 = **3-4回**
- 複数DB横断 → 直接アクセスできるものを先に取り、shard検索は後回し

## 1) 条文（法令）→ ai-law-db

入口: https://jplawdb.github.io/html-preview/ai-law-db/quickstart.txt

**検索方法**
- 条番号が判明: `https://jplawdb.github.io/html-preview/ai-law-db/text/{law_code}/{article}.txt` を直接読む（**1回で完結**）
  例: 措置法66条の7 → https://jplawdb.github.io/html-preview/ai-law-db/text/sozei_tokubetsu/66-7.txt
  例: 法人税法22条 → https://jplawdb.github.io/html-preview/ai-law-db/text/hojinzei/22.txt
  例: 法人税法施行令4条の2 → https://jplawdb.github.io/html-preview/ai-law-db/text/hojinzei_seirei/4-2.txt
  表記ルール: 「第66条の7」→ `66-7`（「の」= `-`）
- 条番号が曖昧/条名から探す: https://jplawdb.github.io/html-preview/ai-law-db/data/resolve_meta_corp/index.json → `{law_code}/{bucket}.json`
  bucket = 条文キー先頭の数字（例: 39-14 → bucket `39`）
- 法令略称が不明: https://jplawdb.github.io/html-preview/ai-law-db/data/law_aliases.json で law_code を確定
- 根拠URL: `https://jplawdb.github.io/html-preview/ai-law-db/enhanced/{law_code}/{article}.html#pX` (#pX=項, #pX-iY=号)

**主要law_code**
- hojinzei / hojinzei_seirei / hojinzei_kisoku : 法人税法/施行令/施行規則
- sozei_tokubetsu / sozei_tokubetsu_seirei : 租税特別措置法/施行令
- shotokuzei / shotokuzei_seirei : 所得税法/施行令
- shohizei / shohizei_seirei : 消費税法/施行令
- sozokuzei / sozokuzei_seirei : 相続税法/施行令
- kokuzei_tsusoku / kokuzei_tsusoku_seirei : 国税通則法/施行令
- kaishahou / kaishahou_seirei / kaishahou_kisoku : 会社法/施行令/施行規則
- shouhou : 商法
（各法令にはさらに _kisoku（施行規則）あり。全24法令。出典: e-Gov法令検索）

## 2) 通達 → ai-tsutatsu-db

入口: https://jplawdb.github.io/html-preview/ai-tsutatsu-db/llms.txt

**検索方法**
- 項番が判明: `https://jplawdb.github.io/html-preview/ai-tsutatsu-db/text/{doc_code}/{item_id}.txt` を直接読む（**1回**）
  例: 法基通1-1-1 → https://jplawdb.github.io/html-preview/ai-tsutatsu-db/text/hojinzei_kihon_tsutatsu/1-1-1.txt

- 通達名が不明: https://jplawdb.github.io/html-preview/ai-tsutatsu-db/data/doc_aliases.json で doc_code を確定

**doc_code一覧**
- hojinzei_kihon_tsutatsu : 法人税基本通達

- shohizei_kihon_tsutatsu : 消費税基本通達

- sozei_tokubetsu_tsutatsu_hojinzei : 租税特別措置法関係通達（法人税編）

## 3) 判決・裁決 → ai-hanketsu-db

入口: https://jplawdb.github.io/html-preview/ai-hanketsu-db/quickstart.txt

**検索方法**
- case_idが判明: `https://jplawdb.github.io/html-preview/ai-hanketsu-db/houjinzei/core/{id}.txt` を直接読む（**1回**）
  例: https://jplawdb.github.io/html-preview/ai-hanketsu-db/houjinzei/core/13436.txt
  読み方: YAML（メタデータ）→ 判決要約 → 注意書き
- キーワード検索:
  1) https://jplawdb.github.io/html-preview/ai-hanketsu-db/houjinzei/data/shards_index.json → shard番号特定
  2) `https://jplawdb.github.io/html-preview/ai-hanketsu-db/houjinzei/data/shards/shard-XX.txt`（TSV: issue_hint列等でキーワード検索）
  3) `https://jplawdb.github.io/html-preview/ai-hanketsu-db/houjinzei/core/{id}.txt`（要約本文）

**収録**（出典: 裁判所裁判例検索・国税不服審判所公表裁決事例等）
- houjinzei/ : 法人税判決 990件
- saiketsu-houjinzei/ : 法人税裁決（同構造: data/shards/ + core/）

NOTE: `core/batch-*.txt` は内部用。入口ナビには使わない。

## 8) 法人税別表（構造・各欄・転記関係）→ beppyo-db

入口: https://jplawdb.github.io/html-preview/beppyo-db/llms.txt（推奨: まずこれ。別表一覧表・転記関係・検算式・税率を記載）

**検索方法**
- 別表番号が判明: `https://jplawdb.github.io/html-preview/beppyo-db/beppyo/{ID}.txt` を直接読む（**1回**）
  例: 別表四 → https://jplawdb.github.io/html-preview/beppyo-db/beppyo/B04.txt
  例: 別表十五 → https://jplawdb.github.io/html-preview/beppyo-db/beppyo/B15.txt
  ID命名: B{番号}。枝番はハイフン（例: B05-1, B06-2-2, B17-3-5）
- 条文番号から別表を探す: https://jplawdb.github.io/html-preview/beppyo-db/lookup/article-map.txt（条文→別表の逆引き）
- 転記関係を調べる:
  https://jplawdb.github.io/html-preview/beppyo-db/rel/rel-core.txt : 必須5別表(B01,B04,B05-1,B05-2,B02)の相互関係
  https://jplawdb.github.io/html-preview/beppyo-db/rel/rel-to-B04.txt : 各別表→B04への転記一覧
  https://jplawdb.github.io/html-preview/beppyo-db/rel/rel-from-B04.txt : B04→B01→B05(二)→B05(一)の転記チェーン
- 検算不一致の調査: https://jplawdb.github.io/html-preview/beppyo-db/check/kenzan.txt（B04↔B05(一)不一致原因TOP10）
- 作成順序: https://jplawdb.github.io/html-preview/beppyo-db/flow/overview.txt

**txtファイルの読み方（全45ファイル共通フォーマット）**
- 1行目: `{ID} {別表名}｜{正式名称}`
- 2行目: `{根拠条文}｜{適用法人}｜{性格}`
- 3行目: `←{入力元} →{出力先}`（転記関係の要約。先頭3行だけで転記ネットワーク把握可能）
- 以降: ■セクション群（■構造、■欄N:記述、■NTA記載の仕方のポイント、■関連別表、■よくある間違い）
- 欄記述の記法: `欄N: 名称 計算式 ←転記元 →転記先`

収録: 全45別表（B01〜B17-4）。別表一覧・転記関係・検算式の詳細は https://jplawdb.github.io/html-preview/beppyo-db/llms.txt 参照。
